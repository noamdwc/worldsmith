# AutoResearch journal

Append an entry for each session and keep the entries for rejected candidates. Use paths relative to this workspace so results can be found in `runs/`.

## Session template

- **Date and baseline** — controller, run directory, captures out of 32, mean closest distance.
- **Iteration** — number, hypothesis, evidence from a trace, and code change.
- **Result and decision** — run directory and metrics or error, comparison with the retained controller, and whether the candidate was kept or rejected.
- **Findings** — useful discoveries, remaining uncertainty, and final retained metrics.
